# HTML Advanced - Techium

This project is part of the Software Engineering curriculum at Holberton School. It focuses on advanced HTML5 semantic structures, accessibility, webpage organization, and proper document outlines using W3C standards.

## Learning Objectives
- Understanding W3C guidelines and HTML validation.
- Structuring HTML5 pages with semantic tags (header, main, footer, nav, section, article, aside).
- Implementing correct heading hierarchy (h1 to h6).
- Using structural wrappers like div and inline elements like span.
- Creating clean navigation, links, and multiple subpages for the Techium digital agency.
